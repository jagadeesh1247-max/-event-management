AetherMind AI — Enterprise Intelligence & Autonomous Systems
A responsive enterprise AI company landing page built with pure semantic HTML5 and modern CSS3 (zero JavaScript dependencies), showcasing foundation models, agentic workflows, multimodal edge vision, technical benchmarks, leadership, and an enterprise briefing form.
🌐 Live Demo: https://strong-yeot-a6574f.netlify.app

✨ Key Highlights & Sections
Sticky Navigation & CSS-Only Mobile Menu: Responsive top navigation bar with smooth anchor scrolling and a pure CSS checkbox drawer (#nav-toggle) for mobile viewports.
Hero & Neural Core Telemetry: Showcases core metrics (99.99% uptime, <18ms edge token latency, 2M+ context window) paired with an animated pure-CSS orbital neural cluster card (LLM, VISION, AGENTS, GUARD).
Product Ecosystem (#products): Highlights AetherCore LLM, Nexus Agent Studio (featured), and Spectra Vision Engine with capability checklists and action links.
Platform Capabilities (#features): Six-card grid covering Cryptographic Provenance, Private VPC & Air-Gap, Adaptive Speculative Decoding, Continuous LoRA Fine-Tuning, Constitutional Guardrails, and Hybrid RAG Memory.
Industry Applications (#applications): Production use cases across Biotech & Healthcare, Quantitative Finance, Advanced Manufacturing, and Software Engineering with outcome metrics.
Technology Stack & Benchmarks (#technology): Four-layer Aether-4 inference pipeline diagram (Multimodal Ingestion  Sparse MoE Routing  Symbolic Verifier  Zero-Trust Execution) plus CSS progress bars for SWE-Bench Verified (78.4%), GPQA Diamond (84.2%), and MATH-500 (96.8%).
Leadership & Research Team (#team): Four-column leadership grid with gradient initial avatars and role bios.
Enterprise Briefing Form (#contact): Accessible form with CSS :target confirmation feedback (#contact-submitted) and global office/lab details.

🛠️ Tech Stack
HTML5: Semantic landmarks (<header>, <main>, <section>, <article>, <footer>), accessible form labels, and SVG icons.
CSS3: CSS Custom Properties (:root), CSS Grid & Flexbox, backdrop-filter glassmorphism, keyframe orbit/pulse animations, and responsive media queries (1024px and 768px breakpoints).
Zero External Runtime JS: All interactive states (mobile menu toggle, smooth scrolling, benchmark bars, and form confirmation state) work natively in the browser.

🚀 Local Setup & Deployment
Run Locally
Clone or download the repository:
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
Open index.html directly in any modern browser, or serve it with a local static server (such as VS Code Live Server or npx serve .).
Deploy to Netlify
Drag and drop the project folder into Netlify, or connect your GitHub repository to Netlify with Publish directory set to . (root) and no build command required.

🎨 Customization
Colors & Radii: Edit CSS variables at the top of styles.css (--bg-primary, --accent-cyan, --accent-violet, --accent-emerald, --gradient-brand, --radius-lg).
Content & Metrics: Update product cards, benchmark percentages, team members, or contact details directly inside index.html.
